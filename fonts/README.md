# Fonts

Rubik by the Rubik Project Authors, SIL Open Font License 1.1 (`OFL.txt`).
Source: https://github.com/google/fonts/tree/main/ofl/rubik (`Rubik[wght].ttf`, `Rubik-Italic[wght].ttf`).
The static weights here were made with `tools/make-fonts.py` (fontTools instancer), because
Unreal 4.26 draws a variable font at its default weight only.

`fonts.json` maps each of the game's Latin font faces to the Rubik weight that replaces it.
The game's CJK fonts are left alone.
